# 财务管家 · 个人财务管理系统

现代简约风格的个人财务管理网站：HTML/CSS/JavaScript 前端 + Supabase（Postgres 数据库 + Auth 认证 + 实时同步 + 行级安全 RLS），响应式设计，电脑与手机均可使用。

## 快速开始

1. 用任意静态服务器打开（或直接发布上线后访问链接）：
   ```bash
   # 例如
   python -m http.server 3000
   # 访问 http://localhost:3000
   ```
2. 首次使用：注册一个邮箱账号并登录。
3. 数据默认写入你自己的 Supabase 项目（配置已内置，可在「设置 → 云端同步」中修改）。

## Supabase 首次配置（重要）

在 Supabase 控制台 → **SQL Editor → New query**，粘贴项目内 `supabase-schema.sql`（或应用「设置 → 云端同步」中展示的同一段 SQL）并运行，完成：

- 7 张表：`ledgers`（账本）、`categories`（分类）、`records`（记录）、`budgets`（预算）、`templates`（快捷模板）、`banners`（背景）、`bills`（周期性待办账单）
- 全部开启 **RLS 行级安全**，按 `auth.uid()` 隔离，每个用户只能看到自己的数据
- 加入 `supabase_realtime` 发布，实现多设备实时同步

> 已有项目升级：重新执行一次 `supabase-schema.sql`（幂等），会自动补建 `bills` 表并启用 RLS；账册原有数据不受影响。

> 如注册后提示「邮箱尚未验证」，可到 Supabase 控制台 → Authentication → Providers → Email 关闭 **Confirm email**，即可直接登录。

## 功能总览

| 模块 | 能力 |
| --- | --- |
| 记账本 | 选账本 / 大类 / 小类、金额、备注、心仪物品标记、0–5 星评分、底部一键记账模板、月度汇总、预算预警条 |
| 待办账单 | 周期性固定支出（每月/每季度/每半年/每年/自定义）、到期前 3 天预提醒、到期日提醒、确认已付后自动写入账册、逾期标红、本月待付与今年固定支出总览 |
| 好物仓库 | 心仪物品自动联动；上传图片画廊；名称 / 金额 / 已陪伴天数 / 每日成本 / 使用状态；筛选与排序 |
| 统计 | 月度 / 年度收支汇总；小类消费筛选；环形图分类占比；折线图收支趋势 |
| 出租屋账本 | 独立账册：房租 / 水费 / 电费 / 燃气费 / 物业费 / 装修硬装费 / 装修材料费 / 租房软装 / 搬家搬物；固定费用一键生成本月记录 |
| 预算设置 | 每个小类月度限额；绿（<70%）/ 黄（70–100%）/ 红（>100%）三色预警 |
| 设置 | 账号、Supabase 连接与测试、建表 SQL 一键复制、数据导出 / 导入 / 迁移、分类与模板增删改 |

## 目录结构

```
finance-app/
├── index.html            # 入口（登录页 + 应用外壳）
├── styles.css            # 样式（响应式、浅灰白 #F5F7FA + 深蓝 #1A2B4C + 亮绿 #4ADE80 + 蓝紫 #6366F1）
├── supabase-schema.sql   # 建表 + RLS + 实时同步 SQL
├── js/
│   ├── vendor/
│   │   └── supabase.js   # Supabase SDK（本地内置，避免 CDN 加载失败；CDN 仅作兜底）
│   ├── data.js           # 默认分类 / 模板 / 工具函数
│   ├── store.js          # Supabase / 本地双模式数据层 + Auth + 实时订阅
│   ├── charts.js         # Canvas 环形图 / 折线图（零依赖）
│   ├── app.js            # 路由与页面交互
│   └── bills.js          # 待办账单：渲染 / 增删改 / 提醒 / 确认入账
└── README.md
```

## 说明

- 未配置 Supabase 时自动进入本地模式（数据存浏览器 localStorage），所有功能可完整体验；配置后自动切换云端同步。
- 图片上传会在前端压缩（最长边 720px，JPEG）后以 dataURL 存入记录，画廊直接展示。
- 离线时顶部显示红色离线横幅，恢复联网后自动同步。
