Style Analysis · 风格解析

Gray Gold Glass.灰金玻璃

源自 macOS 原生应用的柔光质感：石灰米灰底色、香槟金磨砂玻璃、冷褐投影，只保留一枚古铜金作为行动色。它比纯白更克制，比奶油色更哑光，适合每天都要打开的记账工具。

设计结论 · 为什么适合
降低金钱焦虑灰金比纯白更克制，古金只出现在“行动”和“关键数字”上，不会制造压迫感。
原生应用质感玻璃层、暖灰阴影、1px 高光边，让网页看起来像 macOS 上的常驻小工具。
数据仍然清晰功能色沿用灰绿 / 赭石 / 石板蓝，预算与收支状态不依赖古金色，避免语义混淆。
落地注意 · 工程侧
  • 对比度：正文 #4B473F on #FCFAF6 约 8.6:1，AA 通过。
  • 性能：backdrop-filter 仅用于侧栏 / 顶栏 / 弹窗，列表项不使用。
  • 降级：不支持模糊时回退为 96% 不透明纸面。
  • 深浅：整套为浅色，夜间模式需另做一套暖灰深色 token。
